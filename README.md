# Employee Record Manager

A simple console-based Employee Record Manager built using Python.

This project allows users to manage employee records through a menu-driven interface. It demonstrates the use of dictionaries, loops, conditional statements, and CRUD (Create, Read, Update, Delete) operations.

## Features

- Add Employee
- View All Employees
- Search Employee by ID
- Update Employee Details
- Delete Employee Record
- Exit Program
- Invalid Choice Handling

## Technologies Used

- Python 3

## Concepts Covered

- Variables
- Input and Output
- Dictionaries
- Nested Dictionaries
- if-elif-else
- while Loop
- CRUD Operations
- User Input Validation
